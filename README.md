# 家庭生日管理器

一个完全本地运行的 Windows / Android 家庭生日工具，同时支持公历和农历。

## 设计目标

- 数据只保存在设备本地，不要求登录、服务器或互联网。
- Windows 与 Android 使用同一套 Python/Flet 代码。
- 支持公历、农历、闰月生日。
- 首页可快速输入：`奶奶 农历腊月二十`、`妈妈 公历5月12日`。
- 自动显示下一个生日对应的实际公历日期以及剩余天数。
- JSON 备份采用“按 ID + 更新时间合并”，适合电脑/手机离线互传。
- 删除使用 tombstone（删除标记），避免另一端旧备份把已删除的人重新带回来。
- 可导出未来 20 年 `.ics`，导入手机/电脑的本地日历后，由系统日历离线提醒。

## 本地数据

应用内部使用 `family_birthdays.json`。Flet 打包后，它位于系统为应用分配的持久数据目录：

- Windows：应用数据目录（AppData）
- Android：应用私有数据目录

正常升级应用不会清空它；卸载应用前建议先导出 JSON 备份。

## 开发运行

建议 Python 3.13。

```powershell
cd family_birthday_manager
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
flet run main.py
```

## Windows 打包

### 方案 A：Flet 原生 Windows 构建

```powershell
flet build windows . --python-version 3.13
```

该路线需要 Visual Studio 的 **Desktop development with C++** 工作负载。

### 方案 B：PyInstaller / flet pack

如果只想快速得到桌面可执行程序，可以使用 Flet 提供的 PyInstaller 路线：

```powershell
flet pack main.py --name FamilyBirthday
```

## Android APK 打包

Windows 可以直接构建 Android APK：

```powershell
flet build apk . --python-version 3.13
```

第一次构建可能需要下载 Flutter / Android SDK / 构建依赖，因此**构建阶段可能需要网络**；生成的 APK 本身不需要联网运行。

## 两端离线同步

推荐流程：

1. 手机添加/修改生日。
2. 点“分享备份”或“导出备份”，得到 JSON。
3. 通过 USB、蓝牙、局域网分享、数据线等任意离线方式传到电脑。
4. 电脑点“导入并合并”。
5. 反向操作一次，可让两边拥有相同数据。

合并不是简单覆盖：不同设备新增的记录会同时保留；同一条记录以 `updated_at` 较新的版本为准。

## 日历提醒

“导出 20 年 ICS”会把每一年生日的实际公历日期写入标准日历文件。

默认每个事件包含：

- 提前 7 天提醒
- 提前 1 天提醒
- 当天提醒

不同系统日历对全天事件提醒时间的解释可能略有差异。

## 特殊日期规则

- 农历生日支持 1900–2099。
- 闰月生日：可设置“没有对应闰月时按普通同月同日过”或“该年不过”。
- 农历三十遇到当年该月只有 29 天时，默认按廿九提醒。
- 公历 2 月 29 日遇平年时，默认按 2 月 28 日提醒。

这些策略后续可以继续做成每个人独立可配置。


## v0.2 局域网双向同步

v0.2 在**没有互联网、没有云服务**的情况下，让 Windows 与 Android 更方便地交换生日数据。

### 应用对应用同步

1. 两台设备连接到同一个 Wi-Fi / 局域网。
2. 在其中一台设备点“局域网双向同步” → “启动本机同步服务”。
3. 主机会显示一个局域网地址和随机 6 位配对码。
4. 另一台设备输入地址与配对码，点“**双向同步**”。
5. 两端 JSON 数据按照记录 ID 与 `updated_at` 自动合并；删除标记也参与合并。

同步完成后，两端都会得到合并结果，不需要经过互联网或第三方服务器。

### 二维码 / 浏览器备用方式

主机同时显示一个二维码。手机可以直接用系统相机扫描，在局域网页面中：

- 下载主机备份；
- 上传手机导出的 JSON；
- 让主机合并数据并下载合并后的 JSON。

这条路径不要求浏览器访问公网。

### 安全限制

- 客户端只允许连接私有地址、回环地址或链路本地地址，拒绝公网 IP。
- 客户端主动绕过系统 HTTP 代理，确保局域网同步直接连接，不经过 Clash / v2rayN 等代理。
- 同步服务只在用户主动开启时存在；关闭同步窗口后服务器立即停止。
- 每次启动都会生成新的 6 位配对码。
- 单次 JSON 数据限制为 2 MiB，远高于正常生日列表的需要。


### 校园网 / 公共 Wi-Fi

v0.2 的局域网同步要求两台设备之间能够直接互访。

部分校园网、酒店 Wi-Fi、公共热点会启用 **AP Isolation / Client Isolation（客户端隔离）**：即使两台设备连的是同一个 Wi-Fi，也会阻止终端彼此访问。这种情况下应用会显示无法连接，但并不表示同步协议或代理绕过逻辑失效。

已实测：
- 手机热点环境：可用；
- Windows 保持 Clash 系统代理开启：可用；
- 某些校园网：由于终端互访限制不可用。

遇到这种情况时，优先改用手机热点或允许设备互访的局域网；JSON 手动备份/合并仍可作为完全离线的备用方案。
